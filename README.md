# //pub/svc/commerce/brickowl

Brick Owl, the LEGO marketplace.

This package can be used for cost estimates for anything built from LEGO
parts, at the prices Brick Owl's sellers ask, once the one line that sends
requests to Brick Owl is written (see below). Placing orders is not
implemented yet.

### Quotes

The provider `brickowl` quotes any part declared with `vendor: lego` and
its LDraw number as its SKU, which is every part of
`//pub/universe/lego/ldraw`. The price is from the lots Brick Owl's sellers
have for sale now, to the country the parts are to be shipped to
(`country`). A lot is bought whole, at its unit price, however few of it
are wanted, so for each part the quote is the lots that between them hold at
least as many as are wanted and cost the least to buy whole - which is not
always the lots of the cheapest pieces. What is quoted is what would be
paid, the pieces over what is wanted included, before shipping and before
any store's minimum order; each line says which lots, from which stores,
with a link to each, what each costs, and how many pieces are over
(`lots`, `bought`, `excess`).

* A part is looked up in Brick Owl's catalogue as an LDraw number and as a
  design ID, and then by the numbers Rebrickable's public catalogue says it
  goes by.
* When the part's own lots cannot fill the order, the moulds LEGO made in
  its place are tried, as Rebrickable records them (`2780`, a Technic pin,
  is also sold as `61332`). Only a mould - the same part made again - is.
* Brick Owl prices each lot in its store's own currency and converts
  nothing, so only the lots priced in `currency` are counted. `condition`
  is `new` or `used`.
* With no colour asked for, the first colours Brick Owl lists the part in
  (three, or `coloursTried`) are priced and the cheapest is quoted.
* A part LDraw draws together with another one, a wheel with its tyre on
  (`41896c01`), is an assembly in `//pub/universe/lego/ldraw`, with an SKU
  of its own; `pc supply quote -r` buys it as its parts.

Answers are kept under `~/.cache/partcad-lego/` (`PARTCAD_LEGO_CACHE`
moves it): the catalogue for a month, the lots for a day.

### The one line that is not written

Brick Owl's [terms](https://www.brickowl.com/terms) say, of its API:
"Tools that access the API must not use AI generated code." This package
was written with an AI assistant, all of it but one line: the one that
sends a request to Brick Owl, in `_send()` in `brickowl.py`. Its docstring
says what the line is and what it is handed. Until a person writes it,
nothing is available here, quietly, and a quote says why. Whether that
division is enough for Brick Owl's terms is for Brick Owl to say.

The terms ask more of a tool than that, and the rest of this package does
it: every request carries a User-Agent of its own, and every lot in a quote
carries the link to it at Brick Owl, which is where a price that is shown
has to point. A marketplace, or a service that provides one, may not use
the API at all.

### The key

The catalogue API needs a key from your Brick Owl profile that Brick Owl's
staff have approved for catalogue access ("Access Brick Owl Catalog"),
which is asked for through its contact page; without it, Brick Owl answers
"Access Denied", and the quote says so. Give it in `~/.partcad/config.yaml`,
never in a package:

```yaml
parameters:
  //pub/svc/commerce/brickowl:brickowl:
    key: ...
```

or as `BRICKOWL_API_KEY` in the environment of the PartCAD daemon.

### Choosing a colour

LDraw parts have no colour: the geometry has none. `color` names one by
Brick Owl's number or name, BrickLink's name for it, LEGO's, or an LDraw
colour as `ldraw:<code>`:

```yaml
providers:
  brickowl-grey:
    type: enrich
    source: //pub/svc/commerce/brickowl:brickowl
    with:
      color: Light Bluish Gray
```

endorse this package; nor does Brick Owl.

### Development

The provider is `brickowl.py`, and it needs nothing but Python's own
library. Its tests run it the way PartCAD does, with a stand-in for
`_send()` that answers in the shapes Brick Owl's API answers in, and ask
neither Brick Owl nor Rebrickable for anything:

```shell
$ pip install pytest
$ python -m pytest tests
```


## Usage
What ten 2 x 4 bricks cost in black, once `_send()` is written:

```shell
$ pc --extra-param '//pub/svc/commerce/brickowl:brickowl.color=Black' \
    supply quote --provider //pub/svc/commerce/brickowl:brickowl //pub/universe/lego/ldraw/Brick:3001#10
```
